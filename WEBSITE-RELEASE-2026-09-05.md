Source branch: `fix/astra-website-2026-09-05`, based on `8610be0b`.

No production deployment or live enquiry was made while preparing this release.

## Buyer journey

The existing source catalogue already includes packing, Okoume and rubberwood,
and the legal address/verification footer fixes. This release retains them and
adds a shorter green/cream homepage with the existing packing-product WebP,
visible verification link, product-to-form presets, explicit unknown-specification
guidance and structured enquiry submission. The photograph is an existing
catalogue asset, not new evidence of a named facility. An exact factory map pin
was not established; visitors are asked to confirm collection/visit instructions.

Native POST adds `enquiry` JSON with version, product, grade, thickness,
dimensions, quantity, unit, destination, incoterm, source_page, original_text and
help_me_choose. `enquiry_id` is a browser UUID retained for failed-post retries.
Contact fields and a readable legacy description remain. No JavaScript leaves
named form fields available for the backend fallback parser. Accepted enquiries
must be counted server-side: `?sent=1` no longer emits a success event.

## Preserve what production already serves

Production `0581611a` includes four export PRs absent from the source lineage.
`content/export/published-patches.json` captures their exact published research,
transit and navigation fragments, generated by `tools/port_published_export_changes.py`.
The generator applies each fragment once and fails on unexpected source drift;
patches can be retired when their content migrates into the underlying country
data. This preserves later source changes outside those fragments.

The live pin now names `0581611a`. All 320 live photos/root/workflow assets match
the candidate byte-for-byte. Existing URLs, encyclopedia canonical paths and
redirect decisions remain. The two remaining build warnings concern deliberately
rewritten/omitted redirect rules already documented in the generator.
